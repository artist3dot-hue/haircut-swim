# 给 Claude Code 的分阶段提示词

用法：**一个阶段开一个新的云端会话**，把对应提示词整段复制过去。
每个会话开头 Claude Code 会自动读 `CLAUDE.md`，它会按里面的要求再去读 GDD 和美术指南。
一个阶段做完、你试玩满意后，再开下一个阶段。

---

## 阶段 0：搭项目 + 自动部署

```
请按 CLAUDE.md 的技术栈初始化这个项目：Vite + TypeScript（strict），纯 Canvas 2D。
1. 建好 CLAUDE.md 里写的目录结构，main.ts 里跑起固定时间步的主循环，画面是 360×640 竖屏逻辑分辨率、整数倍最近邻放大、PC 横屏两侧留背景
2. 把 docs/art-refs/palette_ramps.json 转成 src/art/palette.ts
3. 建 src/art/sprites.ts 注册表，先把 assets/icons/ 里的 10 个图标注册进去，并在画面上排一行显示，证明加载和像素放大都正确
4. 加 npm scripts：dev、build、preview、typecheck
5. 加 .github/workflows/deploy.yml，推到 main 分支后自动构建并发布到 GitHub Pages（vite base 路径要设对）
6. 创建 docs/PROGRESS.md
完成后按 CLAUDE.md 的“验证”步骤截图检查，提交并推送。告诉我 GitHub Pages 需要我在仓库设置里手动打开哪个选项。
```

## 阶段 1：手感原型（最重要，慢慢打磨）

```
做剪发画面的手感原型，只做 GDD 第 4.2、6、7 节，别的系统先不做。
- 头发：从画面顶部头皮垂下约 150 根 Verlet 头发，持续往下长，受重力轻微摆动，剪刀经过会被推开
- 剪刀：跟随鼠标/手指，平滑跟手，每 0.3 秒自动咔嚓一次（开合动画），用剪刀刃线段与头发求交剪断
- 剪断反馈必须完整：合成咔嚓音（音高随机 ±8%）、断口碎屑、断下部分带旋转下落、飘字、落地变光点飞向左上计数器、计数器弹跳；同帧最多 6 个剪断音，其余并入沙沙底噪
- 连击系统四档（GDD 第 6 节表格），音高随连击上升
- 画风按 docs/ART_STYLE.md 的“头发的画法”，背景用第 1 层小区泳池的青绿瓷砖
- 所有手感参数放在 src/data/juice.ts
- 加一个按 ` 键打开的调试面板，可以实时调：咔嚓间隔、剪刀半径、生长速度、头发数量、各种粒子数量
暂时没有计时和结算，可以无限剪。完成后录几张不同时刻的截图检查，并在 PROGRESS.md 写清楚哪些参数最影响手感。
```

## 阶段 2：一局的完整流程 + 软失败

```
在阶段 1 的基础上，把剪发画面做成完整的一局（GDD 第 4.2、5、12 节）：
- 倒计时（初始 45 秒）、泳帽线、地板线、右侧竖向发量条
- 头发生长随时间加快；发量爆表软失败：本局立即结束、发丝只拿 50%、播放“被头发淹没”的简短动画
- 失败预兆：接近地板线时画面边缘被头发侵占、背景节奏加快
- 所有头发剪到泳帽线以上并保持 3 秒 → 提示“可以去游泳了！”，并给出“再剪一会儿”的选择（收益 ×2、生长加速）
- 结算面板：本局发丝、最高连击、剪断根数
- 加入头发种类：普通、打结、分叉、钢丝、白发（GDD 第 9 节），数据放 src/data/hair.ts
然后验证、截图、更新 PROGRESS.md。
```

## 阶段 3：主界面 + 技能树 + 存档

```
做主界面（GDD 第 4.1 节）和成长系统：
- 主界面竖屏场景：阿发坐在泳池边理发椅上，长发拖地；按 docs/ART_STYLE.md 用代码画像素场景（先做到风格统一，细节可以之后替换）
- 场景物件可点击：阿发（开始一局）、镜子（技能树）、工具架、推车（道具商店，本阶段先放占位）、泳帽（去游泳进度）、收音机（设置）；悬停轻弹 + 显示名字
- 阿发表情随发量变化（慌张 / 期待 / 心疼），待在主界面时头发慢慢长
- 技能树：从中心“一把剪刀”向外展开，约 15 个节点，覆盖锋利、范围、节奏、收获、时间、连击分支；买一个才露出相邻节点；价格 = 基础价 × 1.15^等级；数据放 src/data/skills.ts
- 大数字格式化、localStorage 自动存档（带 version）、设置里可导出/导入存档、调音量
- 场景切换要有过渡动画
验证、截图、更新 PROGRESS.md。
```

## 阶段 4：工具 + 道具 + 大招

```
加入 GDD 第 8、10、11 节中 MVP 需要的部分：
- 电推子：沿移动轨迹持续剪，有持续“嗡”声，推过头发时声音被压低一下；在技能树里解锁
- 普通道具：护发素、梳子、发胶（开局前在推车选，局内按数字键或点图标使用），用金币购买；金发掉金币
- 大招“旋风剪”：连击充能，满了点击释放，全屏清一遍，80ms 顿帧 + 震屏 + 满屏头发飞起
- 稀有头发“金发”“彩虹发”加入，配专属音效和闪星
图标优先用 assets/icons/ 里已有的，没有的按同样画法代码绘制。验证、截图、更新 PROGRESS.md。
```

## 阶段 5：去游泳（第一次转生）

```
做 GDD 第 13 节第 1 层的转生：
- 满足条件后主界面的泳池发光，点击确认后播放转生动画：阿发戴上泳帽跳水 → 游泳 → 回家 → 镜头一转头发又长回来（像素动画，10 秒以内，可跳过）
- 重置发丝和普通升级，获得奖牌（数量按本轮总发丝计算，公式写在 src/data/prestige.ts）
- 奖牌商店：6–8 个永久加成
- “没剪够硬去游泳”的失败结局：被救生员赶出来，拿 20% 奖牌 + 成就
- 目标节奏：新玩家 15–20 分钟完成第一次去游泳。写一个 Playwright 脚本模拟玩家自动打几局，打印第一次达到去游泳条件所用的时间，用来调数值
验证、截图、更新 PROGRESS.md，并在里面给出数值调整建议。
```

## 阶段 6：打磨与试玩调整

```
通读 docs/PROGRESS.md 里的已知问题，然后做一次整体打磨：
- 检查所有手感事件是否都有反馈、有无音效过载
- 手机竖屏触控体验：跟手、误触、震动
- 性能：600 根头发下保持 60fps，必要时给远处头发做批量绘制
- 加一个新手引导（前 30 秒只用文字气泡提示“拖动剪刀”）
- 列出你认为最影响“爽感”的 5 个问题并修掉
验证、截图、更新 PROGRESS.md。
```

---

## 之后的阶段（MVP 之后）

按 GDD 第 13 节一层一层加：第 2 层（游泳馆、头发里的怪、Boss、剃刀卫星）→ 第 3 层（海边、机器人、离线收益）→ …
每层一个会话，提示词模板：

```
实现 GDD 第 13 节第 N 层：场景【……】、新玩法【……】、新工具【……】、新头发【……】。
场景色调按 docs/ART_STYLE.md“每层场景色调”。先读 PROGRESS.md 了解现状。
验证、截图、更新 PROGRESS.md。
```

## 小技巧

- 你试玩后有意见，就在同一个会话里直接说，比如“咔嚓声太闷了，再脆一点”“头发太少，不够爽”，比开新会话省额度。
- 想换正式美术时：把 Aseprite 导出的 png 放进 `assets/`，告诉它“把 sprites.ts 里的 X 换成 assets/xxx.png”。
- 如果它开始改设计文档或换技术栈，提醒它“按 CLAUDE.md 来”。
