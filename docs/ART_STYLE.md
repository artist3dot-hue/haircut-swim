# 美术风格指南

> **所有参考图只参考画风：用色、光影、线条、质感。不要照抄构图、视角和画面布局。**
> 画面布局以 `GDD.md` 第 4 节为准。

## 一句话

**细腻的高分辨率像素画 + 夏日泳池的柔和光 + 带一点幽默的日常感。**
不是 8-bit 色块，也不是粗黑描边的卡通；像素要对齐网格，但细节丰富、有光泽、有空气感。

## 画法规则

1. **像素对齐**：所有图形在整数像素上，放大只用最近邻。
2. **描边**：用物体色阶里的第 0 档（深色同色系），**禁止纯黑描边**。头发本身不描边。
3. **光源**：固定左上方。亮部在左上边缘，暗部在右下边缘 1–2px。
4. **圆柱物体**（瓶子、推子、人物四肢）：竖向高光带在左侧约 20% 处，右侧 25% 为暗部。
5. **造型**：偏细、偏尖、有棱角，**不要胖圆**。剪刀刃要尖，梳齿要清楚。
6. **高光点缀**：稀有物品和头发用 1px 白点 + 四角闪星（✦）表现光泽，别滥用。
7. **图标尺寸**：48×48，物体占画布 80% 左右，四周留透明边。
8. **人物**：阿发比例偏修长，脸部简洁，表情可以漫画化夸张（慌张、握拳、流泪）。头发是全画面细节最多的东西。
9. **数字飘字**：像素字体，白字 + 深青描边；连击越高越偏金色。

## 头发的画法（代码绘制）

- 每根头发 1px 宽的像素线（近景可 2px），颜色沿发丝从根部深 `#031313` 到末端略亮 `#18323c`
- 每 3–5 根头发里有 1 根带高光段（`#324143` → `#819aab` 的一小段），制造光泽
- 画面分前后两层：后层颜色更暗、摆动更慢，前层清晰
- 剪断的碎发保留弯曲形状，下落时旋转；小碎屑是 1px 点
- 金发、白发、彩虹发周围随机出现闪星粒子

## 素材来源说明

- 目前没有外部美术素材。Claude Code 用代码绘制像素图（参考 `assets/icons/` 已有图标的画法与 `palette_ramps.json`）。
- 用户之后会用 Midjourney 出概念图、在 Aseprite 里清理后放进 `assets/`。代码里所有图像都要通过一个 `sprites.ts` 注册表加载，方便以后把代码画的占位图替换成正式图。
