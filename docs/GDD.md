# 《剪发去游泳》游戏设计文档（GDD）

> 暂定名。类型：动作增量 / 割草类。平台：网页优先（竖屏 9:16），之后 Steam 与手机。
> 操作：只用鼠标（手机为手指）拖动。单局 30–90 秒，主线 3–4 小时。

## 1. 一句话

拖着自动开合的剪刀，剪掉长发男人阿发疯长的头发，剪到能戴上泳帽就去游泳；游完回家，头发又长回来了，而且更离谱。

## 2. 设计支柱

1. **每一刀都要爽**：声音、顿帧、头发飞散、发丝吸入，缺一不可。
2. **碾压感循环**：升级后立刻碾压当前头发，再被慢慢追上，再升级。
3. **越长越离谱**：头发、工具、场景一起升级到荒诞。
4. **失败也好笑**：软失败有专属动画和吐槽。

## 3. 故事与主角

阿发留了二十年长发，拖到地上。夏天想去游泳，泳池规定必须戴泳帽，泳帽套不上，于是拿起剪刀。每次游完回家，头发又长回来，他只好去更远的地方游泳：小区泳池 → 市游泳馆 → 海边 → 横渡海峡 → 奥运会。

- 他舍不得剪：剪过"泳帽线"太多会进入**心疼区**，收益下降，主角捂头流泪。
- 表情随发量变化：头发太多时慌张；接近泳帽线时期待握拳；心疼区时捂头。

## 4. 两个主画面

### 4.1 主界面（Hub）：阿发坐在那里

竖屏场景：阿发坐在泳池边的理发椅上（侧面或 3/4 角度），长发拖到地板铺开。**所有功能都是场景里的物件**，点击打开，不用传统菜单按钮：

| 场景物件 | 功能 |
| --- | --- |
| 阿发本人 | 开始剪发（开一局） |
| 墙上的镜子 | 技能树 |
| 工具架 | 工具与装备 |
| 小推车上的瓶瓶罐罐 | 道具商店 |
| 挂钩上的泳帽 | 去游泳进度（发量离泳帽线多远） |
| 泳池 / 门口 | 去游泳（转生，条件满足时发光） |
| 墙上的奖牌 | 成就 |
| 角落的收音机 | 设置（音量、震动、语言、存档导入导出） |

细节：待在主界面时头发缓慢变长，阿发表情跟着变；物件鼠标悬停时轻微弹跳并显示名字；每个转生层换一套房间。

### 4.2 剪发画面（Cut）：从上往下的头发特写

竖屏，头皮在画面最上方（只露出一点头顶和发际线），头发像瀑布一样**从上往下垂并持续往下长**。

- 画面上方约 20% 处有一条**泳帽线**（虚线 + 泳帽小图标）
- 画面底部是**地板线**，头发垂到地板以下即"爆表"
- 右侧一条竖向**发量条**，显示当前发量相对泳帽线和地板线的位置
- 剪断的头发往下掉，落到底部后化成发丝，被吸向左上角的计数器
- HUD：左上发丝数，右上倒计时，下方连击数与大招充能条
- PC 横屏：中间竖屏画面，两侧用模糊背景

## 5. 核心循环

**一局（30–90 秒）**
1. 在主界面升级、选道具，点阿发开局
2. 计时开始，头发不断向下长
3. 玩家拖动剪刀，剪刀每 0.3 秒自动咔嚓，扫过的头发被剪断
4. 剪下的头发化为发丝
5. 时间到正常结算；发量爆表则提前结束（软失败）
6. 回主界面升级

**升级节奏**：每 3–5 局解锁一次明显变强的东西。
**去游泳**：某一局中把所有头发剪到泳帽线以上并保持 3 秒，本局结算后解锁"去游泳"。

## 6. 操作与爽感

操作只有拖动。剪刀自动按节奏开合，玩家只负责找头发最密的地方。

**剪断一根头发的同时**

| 层面 | 做法 |
| --- | --- |
| 声音 | 清脆"咔嚓"，音高随机 ±8% |
| 画面 | 断口以下的部分带旋转和重力下落，头发保持弯曲形态 |
| 碎屑 | 断口蹦出 3–6 个 1px 碎屑 |
| 飘字 | 收益数字从断口弹出上飘 0.6 秒，连击越高字越大越亮 |
| 收集 | 落地后化为发丝光点，沿曲线飞向计数器，计数器缩放弹跳 |
| 顿帧 | 普通头发 0 毫秒；稀有头发 40 毫秒；大招 80 毫秒 |
| 震屏 | 只在大招、连击档位、Boss 受击时，幅度 2–4px |
| 预反馈 | 剪刀经过时附近头发被推开、轻轻摆动 |
| 手机 | 剪断时 `navigator.vibrate(8)`，稀有头发 20 |

**音效**
- 剪刀"咔嚓"（短噪声 + 高频金属音）；电推子持续"嗡"，推过头发时音量被压低一下
- 稀有头发专属：白发清亮"叮"，金发硬币"叮当"，彩虹发上扬琶音，钢丝发"铛"
- 发丝落地的轻"沙沙"声铺底
- 限流：同一帧最多 6 个剪断音，其余并入沙沙层

**连击**：持续剪到头发连击 +1，超过 1 秒没剪到就断。

| 连击 | 收益倍率 | 反馈 |
| --- | --- | --- |
| 10 | ×1.1 | 剪刀音高升一个半音（每 10 连击升一次，最多一个八度） |
| 50 | ×1.5 | 大字"50!" + 重音 + 小震屏 |
| 100 | ×2 | 剪刀拖尾变彩色 |
| 500 | ×3 | 屏幕边缘发光，背景音乐加鼓点 |

## 7. 头发模拟（技术要点）

- 每根头发 = 从头皮挂下来的一串点（Verlet 链，8–16 段），受重力和轻微随机风
- 生长：根部持续"送出"新长度，整根向下延伸；生长速度随时间加快
- 剪断：剪刀咔嚓瞬间，用剪刀刃线段与每段头发求交；交点以下的部分脱离，变成自由落体（保留形状，带角速度）；交点以上的部分留在头上继续长
- 发量 = 所有头发末端低于泳帽线的长度总和；爆表 = 任一 20% 以上头发末端碰到地板线
- 渲染：1–2px 像素线，深黑发色带蓝紫高光（见美术指南），前后两层头发做深浅区分
- 性能目标：600 根头发、60fps；后期头发更多时，远处用"发团"批量绘制

## 8. 剪发工具

每把工具有**锋利度**，头发有**硬度**；锋利度不够剪不动。

| 工具 | 解锁 | 剪法 | 特点 |
| --- | --- | --- | --- |
| 剪刀 | 开局 | 小范围，每 0.3 秒咔嚓 | 手感基准 |
| 园艺大剪 | 第 1 层中期 | 范围大、节奏慢 | 锋利度高，克钢丝发 |
| 电推子 | 第 1 层后期 | 沿移动轨迹持续剪 | 一推一片 |
| 剃刀卫星 | 第 2 层 | 绕剪刀旋转 | 可叠加数量 |
| 理发机器人 | 第 3 层 | 自动巡逻 | 挂机与离线收益 |
| 激光剪 | 第 4 层 | 横向直线 | 穿透一整排 |
| 理发店团队 | 第 4 层 | 各管一片区域 | 大规模自动化 |
| 发型龙卷风 | 第 5 层 | 跟随鼠标 | 终局工具 |

主工具跟随鼠标，卫星、机器人是辅助位，可同时装备。

## 9. 头发种类

难度主要来自"更多、更怪、更值钱"，硬度只是底层数值。

| 头发 | 机制 | 应对 |
| --- | --- | --- |
| 普通黑发 | 一刀断 | — |
| 打结发 | 剪 3 下才断，掉落更多 | 剪速 |
| 分叉发 | 剪断后分裂成两根短发 | 范围工具 |
| 卷发 | 缠住剪刀减速 1 秒 | 护发素、锋利度 |
| 钢丝发 | 锋利度不够剪不动，"铛" | 升级工具 |
| 再生发 | 只剪上半截 3 秒后长回 | 剪到根部附近 |
| 害羞发 | 剪刀靠近就缩回 | 卫星、激光包抄 |
| 辫子 | 剪靠近头皮处整条掉，掉落 ×10 | 找到根部 |
| 白头发 | 发丝 ×10 | — |
| 金发 | 掉金币 | — |
| 彩虹发 | 全场加速 5 秒 | — |
| "那一根" | 极稀有，开特殊道具，全场静音一拍再重击 | — |

**藏在头发里的怪**：头皮屑精、虱子、梳子怪藏在头发里，剪刀不能直接打，要把剪下的碎发甩过去砸。小怪掉金币；Boss（如"虱子王"）限时打败，掉"发根"（解锁新工具和大招）。

## 10. 道具

**普通道具**（金币购买，一局一次，开局前选）：

| 道具 | 效果 |
| --- | --- |
| 护发素 | 10 秒内头发变软，卷发不缠 |
| 梳子 | 把附近头发梳到一起，一剪一大片 |
| 发胶 | 冻结生长 5 秒 |
| 吸尘器 | 自动吸走全场掉落 |
| 生发水 | 本局生长 ×2、收益 ×3 |

**特殊道具**（永久，来自 Boss、"那一根"、转生商店）：

| 道具 | 效果 |
| --- | --- |
| 泳帽碎片 | 每层集齐 3 片，泳帽线放宽 10% |
| 祖传剃刀 | 5% 暴击，一刀剪断一片 |
| 老理发师的围裙 | 断连判定 1 秒 → 1.5 秒 |
| 魔镜 | 稀有头发发光 |
| 理发店会员卡 | 升级价格 −10% |
| 救生员的哨子 | 爆表结算比例 50% → 75% |

## 11. 技能树与大招

技能树在主界面的"镜子"里打开，从中心"一把剪刀"向外展开，买一个节点才露出相邻节点。

| 分支 | 节点示例 |
| --- | --- |
| 锋利 | 锋利度、暴击率、对钢丝发伤害 |
| 范围 | 剪刀半径、推子宽度、卫星数量 |
| 节奏 | 咔嚓间隔、跟手灵敏度 |
| 收获 | 发丝倍率、稀有率、吸入半径 |
| 时间 | 单局 +5 秒 |
| 连击 | 断连宽限、倍率上限 |
| 自动化 | 机器人数量、离线收益 |

**大招**靠连击充能（不是冷却计时），一局带 1–2 个：

| 大招 | 效果 |
| --- | --- |
| 旋风剪 | 全屏清一遍，满屏头发飞起 |
| 时间静止 | 头发停长 5 秒，画面变灰只有剪刀在动 |
| 光头时刻 | 5 秒内收益 ×10，数字变金色 |
| 梳理大法 | 全屏头发梳到一处，一刀剪掉 |
| 发型师之魂 | 按提示路线剪出图案得大奖 |

## 12. 软失败

失败只损失当局部分收获，永不丢升级和解锁。

| 情况 | 结果 |
| --- | --- |
| 时间到，没剪到泳帽线 | 正常结算，拿全部发丝 |
| 发量爆表 | 立即结束，发丝 50%，播放"被头发淹没"动画 |
| 达到泳帽线后选"再剪一会儿" | 收益 ×2、生长加速；爆表则游泳奖牌减半 |
| 没剪够硬去游泳 | 被救生员赶出来，拿 20% 奖牌 + 成就 |

**预兆**：接近地板线时画面边缘被头发侵占、音乐加快、阿发表情变慌。

## 13. 转生（去游泳）

去游泳 = 重置发丝和普通升级，获得永久货币，进入下一层场景。每层带一个新玩法。

| 层 | 场景 | 永久货币 | 新玩法 |
| --- | --- | --- | --- |
| 1 | 小区泳池 | 奖牌 | 基础剪发、连击、软失败 |
| 2 | 市游泳馆 | 奖杯 | 头发里的怪、第一个 Boss、剃刀卫星 |
| 3 | 海边沙滩 | 贝壳 | 地图可上下滚动、机器人、离线收益 |
| 4 | 横渡海峡 | 浪花 | 头发随水流漂动、激光剪、理发店团队 |
| 5 | 奥运会 | 金牌 | 观众欢呼替代连击音效、发型龙卷风 |

转生动画：阿发戴泳帽跳水 → 游完回家 → 镜头一转头发又长回来。结局：奥运夺冠，摘泳帽的瞬间头发像瀑布涌出，进入无尽模式。

## 14. 经济与数值（起始假设，需实测调整）

| 货币 | 来源 | 用途 | 转生时 |
| --- | --- | --- | --- |
| 发丝 | 剪头发 | 技能树 | 重置 |
| 金币 | 金发、小怪 | 一次性道具 | 重置 |
| 发根 | Boss | 新工具、大招 | 保留 |
| 奖牌等 | 去游泳 | 永久加成 | 保留 |

- 单根收益 = 基础值 × 头发倍率 × 连击倍率 × 永久加成
- 升级价格 = 基础价 × 1.15^等级
- 第一次去游泳：15–20 分钟；之后每层 30–50 分钟
- 每层头发基础硬度约为上一层 3–5 倍
- 任何时候技能树上至少有一个买得起或快买得起的节点

## 15. MVP（第一个可玩版本）

只验证"拖着剪刀剪一分钟爽不爽"，能玩到第一次去游泳就算完成：

- 第 1 层场景：主界面 + 剪发画面
- 工具：剪刀、电推子
- 头发：普通、打结、分叉、钢丝、白发
- 完整剪断反馈与连击四档
- 发量爆表软失败
- 约 15 个节点的技能树
- 大招：旋风剪
- 第一次去游泳 + 奖牌商店
- 自动存档
